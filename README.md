# PhuruShekar.com
My personal site: plain HTML and CSS, served by GitHub Pages.

Edit `index.html`, `style.css` and `script.js`; the résumé is `assets/Phuru_Shekar_Resume.pdf`.
Food and hikes live in `food.json` and `hikes.json` (how to add one: `docs/explore-content.md`).
The Music tab reads a `music.json` built daily from Last.fm (`docs/music-pipeline.html`).
