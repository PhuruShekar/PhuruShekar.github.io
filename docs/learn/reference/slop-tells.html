Slop tells

The defaults that make a page look generated, what to use instead, and the evidence. Rule T2 in 3-look.md; checked by K9.

A tell isn’t wrong. It’s a default nobody chose. Remove it, then fill the space with substance (scale, real content, real pictures, a field of color), never with a different ornament.

TellInsteadEvidence (Taste Skill study: share of high- vs low-scored sites)

Exempt: code in pre/code, real data tables, form fields, and a real product screenshot’s own chrome. Source: Taste Skill, “House rules”.
