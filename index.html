hARk

Senior capstone, Rutgers · 2020

An AR app and a wearable device that help people who are hard of hearing see and feel sound.

The phone shows what’s being said and where sounds come from; the wearable turns them into touch. The code splits into speech-to-text, a sound classifier, a direction finder and a server that ties them together.

Built with Java, Python, and Raspberry Pi

Team Josh Siegel, Aditya Verma, and Shantanu Laghate

Minerva

Software Engineering term project, Rutgers · 2020

Quizzes, questions and feedback on top of existing learning management systems.

The repository is the mobile half of the system: a React Native app built with Expo that shares a MongoDB database with the web half through the MongoDB Stitch API.

Built with React Native, Expo and MongoDB

Team Justin May, Salman Omer, Joshua Olazo, Brian Ma, Skyler Lee, Jonathan Hong, and Jacob Battipaglia

Brewba

Bitcamp 2019

An automated bubble tea machine on a conveyor belt.

A cup rides the belt past four stations: boba mix drops in, a coffee pot adds hot water, tapioca pearls fall in, and a stirrer drops for you to mix. A Python script starts the run over USB, an Arduino Uno drives the motors, and a Wemo smart plug switches the coffee pot on.

Built with Arduino, Python, IoT sensors and devices, and lots of duct tape

Team Ali Mohamad and Diane Tran

  • Devpost

Gradian

PennApps 2018 · Winner, Best Education Hack

Anonymous questions, live feedback and in-class quizzes.

Students provide real-time feedback to the lecturer in a phone app while professors run warm-up questions with a built-in clicker. The web app gives students a live transcript, then a summary of key points and further reading when the lecture ends.

Built with React, React Native, Redux, Firebase, Python and the Google Web Speech API

Team Jeane Carlos, Ali Afzal, and Aram Baghdassarian
